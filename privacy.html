TOP LINKS

Privacy

Your favorites stay on your device.

Last updated: 21 October 2026

Top Links does not require an account. Its directory features work in your browser.

What the site saves

Your browser's local storage holds favorite website IDs, your selected theme, useful-site visit counts, sorting preferences, and any catalog drafts you create in the admin editor. These choices are not sent to a Top Links account or database.

You can remove this information through your browser's site-data settings. Removing it resets your saved choices.

Searches and external links

A search is sent to your selected provider when you submit it. Clicking a website link opens that website, which follows its own privacy policy. The directory filter searches locally on this page.

Hosting and feedback

GitHub Pages hosts the published site and may process request information under GitHub's privacy statement. Feedback submitted through GitHub is handled by GitHub and is publicly visible in the issue tracker.

Location and icons

The country indicator is estimated from your browser's timezone. The site does not request precise GPS location. Website logos are stored with the site rather than requested from a favicon service while you browse.

GitHub-only content management

The directory catalog is fetched from this website. No outside analytics or live visitor counters run on the current site. Fonts and icons are bundled with it.

If you use the admin editor, catalog drafts are saved in this browser. An optional GitHub access token is held only in memory for the current tab and sent only to api.github.com to read or update the configured repository. It is not saved in browser storage or in the catalog.

Website suggestions open a prefilled GitHub issue. You decide whether to submit it on GitHub using your GitHub account; issues and any information you include in them are public.
