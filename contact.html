Contact

Help make the directory better.

Last updated: 21 October 2026

Have a question, feedback, or a useful website to suggest? Get in touch by email or Facebook.

Send feedback on GitHub

Include the website name, its URL, and a short explanation. For a display problem, describe your browser and screen size.

Open a GitHub issue ↗

A GitHub account is required to submit an issue. Issues are public, so avoid sharing passwords, private documents, or personal information. If new issues are unavailable, check the repository for its current feedback options.

Suggest a website

Use the website suggestion form to prepare a GitHub issue with the official URL, category, and description. Review and submit it on GitHub. Suggestions are reviewed before they are added.
